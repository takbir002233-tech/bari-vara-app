# 🏢 স্মার্ট বাড়ি ভাড়া ও বিদ্যুৎ বিলিং সিস্টেম (GitHub Auto APK Build)

এই রিপোজিটরিটি ব্যবহার করে আপনি **কোনো কোডিং বা অ্যান্ড্রয়েড স্টুডিও ছাড়াই সরাসরি GitHub থেকে ১-ক্লিকে আসল Android APK ফাইল তৈরি ও ডাউনলোড** করতে পারবেন।

---

## 🚀 কিভাবে GitHub থেকে APK ফাইল বানাবেন (ধাপ অনুযায়ী নির্দেশিকা):

### ধাপ ১: GitHub-এ একটি নতুন রিপোজিটরি তৈরি করুন
১. [GitHub.com](https://github.com/) এ গিয়ে লগইন করুন (অ্যাকাউন্ট না থাকলে একটি ফ্রি অ্যাকাউন্ট খুলুন)।
২. উপরে ডানে **`+` (Plus)** আইকনে চাপ দিয়ে **"New repository"** চাপুন।
৩. Repository name দিন: `bari-vara-app`
4. এটি **Public** রেখে নিচে **"Create repository"** বাটনে চাপ দিন।

---

### ধাপ ২: এই ফোল্ডারের সমস্ত ফাইল আপলোড করুন
১. তৈরি হওয়া রিপোজিটরির পেজে **"uploading an existing file"** লিঙ্কে চাপ দিন।
২. এই নতুন ফোল্ডারের (`scratch/bari-vara-github-app`) সমস্ত ফাইল ও ফোল্ডার ড্র্যাগ অ্যান্ড ড্রপ করে GitHub-এ আপলোড করুন:
   - `index.html`
   - `style.css`
   - `app.js`
   - `lucide.min.js`
   - `html2pdf.bundle.min.js`
   - `manifest.json`
   - `package.json`
   - `capacitor.config.json`
   - `icon.png`, `icon-192.png`, `icon-512.png`, `icon.svg`
   - `.github/workflows/build-apk.yml`
৩. নিচে **"Commit changes"** বাটনে চাপ দিন।

---

### ধাপ ৩: অটোমেটিক APK তৈরি ও ডাউনলোড
১. ফাইল আপলোড করার সাথে সাথে GitHub-এর **"Actions"** ট্যাবে স্বয়ংক্রিয়ভাবে APK বিল্ডিং শুরু হয়ে যাবে (সময় লাগবে ১-২ মিনিট)।
২. **"Actions"** ট্যাবে যান এবং চলমান **"Build Android APK"** কাজের ওপর ক্লিক করুন।
৩. কাজ শেষ হলে নিচে **Artifacts** সেকশনে **`Bari-Vara-Smart-Billing-App-APK`** নামে জিপ/APK ফাইল দেখতে পাবেন।
৪. ওই ফাইলে ক্লিক করলেই সরাসরি **অফিশিয়াল Android APK** ডাউনলোড হয়ে যাবে!
